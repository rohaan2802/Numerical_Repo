Overview

Numerical Computing (CS-2008) at FAST-NUCES Islamabad. The repository has nine lecture sets with their Python notebooks, assignments and a home task in Python, sessional exams, quizzes, the HPCG final project, supporting material and my study notes.

Unit 1

Errors

Number representation, floating-point arithmetic, round-off, truncation and catastrophic cancellation.

Unit 2

Roots & interpolation

Bisection, fixed-point, Newton and secant methods; Lagrange, Newton, Hermite, splines and least squares.

Unit 3

Calculus & ODEs

Numerical differentiation and integration, Euler and Runge–Kutta methods for initial value problems.

Unit 4

Linear algebra

Gaussian elimination, LU, iterative solvers, Gram–Schmidt, QR and SVD; HPCG project.

Get the Files

Clone everything with Git, then open the notebooks in Jupyter.

Clone the repository

Command
git clone https://github.com/rohaan2802/Numerical_Repo.git

Install the Python packages

Command
pip install numpy scipy matplotlib jupyter

Open the notebooks

Command
jupyter notebook

The .py files run with python file.py; the .sln files open the same code in Visual Studio. The 136 MB Computational Mathematics textbook is too large for Git and is attached to Release v1.0.
