## Course Overview

Numerical Computing (CS-2008) at FAST-NUCES Islamabad. The repository has nine lecture sets with their Python notebooks, assignments and a home task in Python, sessional exams, quizzes, the HPCG final project, supporting material and my study notes.

## Topics Covered

| Unit | Topics |
|---|---|
| **Unit 1 – Errors** | Number representation, floating-point arithmetic, round-off, truncation and catastrophic cancellation. |
| **Unit 2 – Roots & interpolation** | Bisection, fixed-point, Newton and secant methods; Lagrange, Newton, Hermite, splines and least squares. |
| **Unit 3 – Calculus & ODEs** | Numerical differentiation and integration, Euler and Runge–Kutta methods for initial value problems. |
| **Unit 4 – Linear algebra** | Gaussian elimination, LU, iterative solvers, Gram–Schmidt, QR and SVD; HPCG project. |

## Running the Code

```bash
git clone https://github.com/rohaan2802/Numerical_Computing_Repo.git
cd Numerical_Computing_Repo
pip install numpy scipy matplotlib jupyter
```

- **Jupyter notebooks (`.ipynb`):** run `jupyter notebook` (or open them in VS Code or Google Colab) and run the cells from the top. GitHub also shows them, with their plots, in the browser.
- **Python scripts:** run them directly, for example `python "Assignments/Assignment_02/interpolation.py"` or `python HomeTask/HomeTask.py`.
- **Visual Studio:** `Assignment_03.sln` and `HomeTask.sln` open the same scripts as Python projects in Visual Studio with the Python workload installed.
- **Final project:** follow [HPCG-Project-Setup-Guide.md](NC_Final_Project/HPCG-Project-Setup-Guide.md) to build and run the HPCG benchmark under WSL.
